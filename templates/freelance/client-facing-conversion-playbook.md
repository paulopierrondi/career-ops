# Client-Facing Conversion Playbook

Use this to make Paulo look like the best professional with the best defensible price and timeline. Do not expose internal AI/LLM/agent tooling unless the client explicitly asks about the technical stack of an AI deliverable.

## Core Positioning

The client should feel:

1. Paulo understood the real problem.
2. Paulo can start with a small visible result.
3. Paulo is cheaper because the first scope is smaller, not because quality is lower.
4. Paulo is faster because the process is organized.
5. Paulo is safer because tests, documentation, handoff and boundaries are explicit.

Default client-facing line:

```text
Eu consigo entrar com uma primeira entrega bem enxuta para voce ver resultado rapido, sem precisar comprar o projeto inteiro agora.
```

## 5-Line Proposal Formula

```text
Oi, {{client_name}}. Li o projeto e o ponto principal parece ser {{real_problem}}.

Para ganhar velocidade, eu comecaria por {{first_visible_result}} em {{timeline}}.

O escopo fica fechado em {{scope_boundary}}, com teste e handoff.

Valor de entrada: {{net_price}} liquido.

Se essa primeira etapa fizer sentido, deixamos {{phase_2}} como evolucao separada.
```

## Objection Replies

### "Tem proposta mais barata"

```text
Entendo. Para competir em preco sem sacrificar qualidade, eu posso reduzir a primeira entrega para {{smaller_scope}} por {{smaller_price}}.

Eu prefiro cortar escopo, nao cortar teste/documentacao. Assim voce recebe algo menor, mas utilizavel, e a gente evolui depois se fizer sentido.
```

### "Consegue fazer mais rapido?"

```text
Consigo acelerar se fecharmos a primeira etapa em {{fast_scope}}. Eu deixaria {{excluded_scope}} para a fase 2, assim voce recebe algo funcional em {{fast_timeline}} sem abrir risco de retrabalho.
```

### "Quero tudo incluso"

```text
Da para chegar no escopo completo, mas eu nao recomendo comecar por tudo de uma vez. O caminho mais seguro e validar primeiro {{first_slice}}, porque isso define a base para {{full_scope}} sem desperdicio.
```

### "Por que escolher voce?"

```text
Porque eu vou direto no que reduz risco: escopo fechado, primeira entrega visivel, teste, documentacao e caminho de evolucao. Voce nao fica comprando uma promessa grande; recebe um primeiro resultado para decidir o proximo passo.
```

## Do / Avoid

Do:

- "primeira entrega visivel"
- "escopo fechado"
- "teste e handoff"
- "valor de entrada"
- "fase 2 separada"
- "cortar escopo, nao qualidade"

Avoid:

- "uso varios LLMs"
- "minha IA faz rapido"
- "meus agentes internos"
- "barato porque uso IA"
- "garanto resultado comercial"
- "me chama fora da plataforma"
